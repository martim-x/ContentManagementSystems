(внутри файла подписано «ЛАБОРАТОРНАЯ РАБОТА №6») + `labs/Joomla/J3(в помощь).pdf`.
Сайт — «Город24» из ЛР5/ЛР6 (Joomla 5), сдаётся как README.md + скрины в `report/`.

## Осталось

1. Импортировать `/tmp/lab7-from-lab6.sql` в базу `db7`.
2. Скопировать файлы сайта из тома `cms-joomla-lab6_joomla_data` в
   `cms-joomla-lab7_joomla_data` (helper-контейнер с двумя томами),
   поднять `web7`, `chown -R www-data:www-data /var/www/html`.
3. `depends_on` — скрипт `lab7-prepare.php` (порт/MFA/пароли/регистрация).
4. Скрипты ACL (Joomla ACL через PDO, как в ЛР5/ЛР6):
   - `lab7-users.php` — группы `Деканат`, `Старосты`, `Студенты` (parent = Registered)
     и по 3 старосты/студента + декан;
   - `lab7-levels.php` — уровни доступа `Для студентов`, `Для старост`,
     `Для старосты группы №1`, `Для старост групп №2 и №3`,
     `Для студентов группы №3`;
   - `lab7-categories.php` — 3 категории задания 2 + материалы + правила
     `core.create` в `jos_assets` (кто может публиковать);
   - `lab7-permissions.php` — права групп в «Общих настройках» (com_content,
     com_menus, com_config/com_users — назначение уровня просмотра);
   - `lab7-menu.php` — пункты меню: регистрация, вход/выход,
     «Создать материал» (с ограничением по уровню доступа);
   - `lab7-verify.php` — проверка фактической видимости по каждой группе.
5. `setup-lab7.sh` — идемпотентный пайплайн целиком (перенос, скрипты,
   проверки curl: гость не видит закрытые материалы).
6. Скрины в `lab7/report/` (канон `taskN_<описание_на_русском>.png`) через
   браузер: вход гостем/студентом/старостой/деканом и проверка видимости,
   группы пользователей, уровни доступа, права категорий, права в «Общих
   настройках», регистрация и активация, публикация от старосты.
7. `lab7/README.md` — задание → реализация → как проверить + заметки к защите.
8. Коммит `лр7: …` и пуш в `ContentManagementSystems` (ветка `main`).
