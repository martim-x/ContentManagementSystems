# Oracle APEX

Лабораторные по APEX выполняются в бесплатном облачном сервисе — локальная установка не требуется:

1. Перейти на https://apex.oracle.com
2. **Get Started for Free** → **Free Sign Up**
3. Заполнить форму и нажать **Request workspace**
   - Workspace — фамилия в транслитерации (например, `Marushko`)
   - Логин/пароль — произвольные, сохранить
4. Подтвердить по письму на почту и войти в workspace

Docker-compose здесь не предусмотрен: официальный образ Oracle APEX не распространяется как простой контейнер, а задания рассчитаны именно на облачный workspace.
