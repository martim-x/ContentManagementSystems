# ЛР9 — Drupal: работа с публикациями и меню

Дисциплина «Системы управления контентом». Задание — `labs/Drupal/Drupal_2.pdf`
(в документе «Лабораторная работа №9»). Сайт — городской новостной портал «Город24»,
продолжение ЛР8; каталог ноутбуков Lenovo — раздел портала «Техника».

## Стенд

- Собственный `Dockerfile`, `docker-compose.yml`: проект `cms-drupal-lab9`,
  контейнеры `db9` / `web9` / `adminer9`.
- Drupal 11.4, тема **Bootstrap 5**. Порты: сайт **8106**, Adminer **8107**.

| Что | Адрес | Логин |
|---|---|---|
| Сайт | http://localhost:8106 | — |
| Админка | http://localhost:8106/user/login | `admin` / `Gorod24!Admin2026` |
| Adminer | http://localhost:8107 | сервер `db`, пользователь `drupal` |

## Запуск

```sh
cd lab9
docker compose up -d --wait
sh setup-lab9.sh      # идемпотентен: сначала база ЛР8, затем конфиг ЛР9
```

Модули: Admin Toolbar, Pathauto, Token, Metatag, Webform, Chaos tool suite, Colorbox.
База ЛР8 (таксономия, тип «Ноутбук», каталог из 10 карточек) разворачивается тем же
скриптом `scripts/lab8-config.php`.

## Что сделано по заданиям

### Задание 1 — регион с двумя блоками

Регион `sidebar_first` темы Bootstrap 5 с двумя блоками произвольного содержания:
«О портале» (о «Город24» и ссылка «Прислать новость в редакцию») и «Рубрики»
(список ссылок на шесть рубрик портала).
Скрины: `report/task1a_регион_два_блока_настройка_блоков.png` (Block layout),
`report/task1b_два_блока_в_боковой_колонке_на_странице.png` (вывод на странице).

### Задание 2 — материал типа Article и ссылка в меню

Статья «Как работает редакция «Город24»» (материал типа `article`, поле body, формат
`basic_html`), пункт меню «О редакции».
Скрины: `report/task2a_статья_настройки_материала.png` (форма редактирования и её настройки),
`report/task2b_статья_о_редакции_на_сайте.png` (опубликованная статья).

### Задание 3 — три дополнительные страницы

| Страница | Алиас | Что на ней | Скрин |
|---|---|---|---|
| История фирмы Lenovo | `/stranicy/istoriya-firmy-lenovo` | текст истории раздела «Техника», 2 фотографии (стиль `history_photo`), 3 ссылки на официальный сайт Lenovo | `report/task3a_история_фирмы_текст_картинки_ссылки.png` |
| Галерея ноутбуков Lenovo | `/stranicy/galereya-noutbukov-lenovo` | 8 фотографий, миниатюры со стилем `gallery_thumb` | `report/task3b_галерея_миниатюры_colorbox.png` |
| Прайс-лист ноутбуков Lenovo | `/stranicy/prays-list-noutbukov-lenovo` | простая таблица из 10 строк (модель, серия, цена) | `report/task3d_прайс_лист_таблица.png` |

Галерея открывается в лайтбоксе **Colorbox** (модуль `colorbox` + библиотека
`libraries/colorbox/jquery.colorbox-min.js` 1.7.0, форматтер «Colorbox» с группировкой):
`report/task3c_галерея_лайтбокс_colorbox_работает.png` — затемнение, окно с фото, подпись,
стрелки и счётчик «1 of 8».

### Задание 4 — меню

- Главное меню: «Главная», «Рубрики» (пустая ссылка `<nolink>`) с шестью подпунктами-рубриками,
  «Каталог» (пустая ссылка `<nolink>`) с четырьмя подпунктами-сериями словаря «Lenovo»
  (IdeaPad, ThinkPad, V, Yoga), «Техника» (`/noutbuki`), «История фирмы», «Галерея»,
  «Прайс-лист», «О редакции».
  Скрины: `report/task4a_меню_структура_каталог_подпункты.png` (структура меню),
  `report/task4d_меню_на_сайте_каталог_и_рубрики.png` (меню на сайте с раскрытым «Каталог»).
- Дополнительное меню «Дополнительное меню» (Главная, История, Галерея, Прайс-лист,
  Прислать новость), размещено в регионе `footer` штатным блоком темы.
  Скрины: `report/task4b_дополнительное_меню_настройка.png`, `report/task4c_дополнительное_меню_в_футере.png`.

## Конфигурация кодом

`scripts/lab9-config.php` (идемпотентен) — блоки боковой колонки, статья, три страницы
раздела «Техника» с изображениями, пункты меню и подпункты (рубрики, серии), блок футера,
алиасы. Устаревшие материалы
и пункты меню прошлых прогонов удаляются.

## Проверка

`setup-lab9.sh` в конце выполняет curl-проверки: ответ главной, блок «О портале» в боковой
колонке, все три страницы раздела «Техника», `colorbox` в разметке галереи, `<table>` в прайсе,
статья о редакции, «Дополнительное меню» в футере.
