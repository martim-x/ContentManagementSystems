# ЛР8 — Drupal: знакомство с Drupal

Дисциплина «Системы управления контентом». Задание — `labs/Drupal/Drupal_1.pdf`
(в документе «Лабораторная работа №8»). Сайт «Город24», каталог ноутбуков Lenovo.

## Стенд

- Собственный `Dockerfile` (образ `drupal:11` + drush + настройки PHP), `docker-compose.yml`:
  проект `cms-drupal-lab8`, контейнеры `db8` / `web8` / `adminer8`.
- Drupal 11.4, тема **Bootstrap 5** (нестандартная), редакция `standard`.
- Порты: сайт **8104**, Adminer **8105**.

| Что | Адрес | Логин |
|---|---|---|
| Сайт | http://localhost:8104 | — |
| Админка | http://localhost:8104/user/login | `admin` / `Gorod24!Admin2026` |
| Adminer | http://localhost:8105 | сервер `db`, пользователь `drupal` |

## Запуск

```sh
cd lab8
docker compose up -d --wait
sh setup-lab8.sh      # идемпотентен: повторный запуск не создаёт дубликатов
```

## Что сделано по заданиям

### Задание 1 — установка Drupal

Развёрнут Drupal 11 через `drush site:install standard` (PostgreSQL в контейнере `db8`).
Скрин: `report/task1a_установка_версия_и_состояние_сайта.png` (страница Status report).

### Задание 2 — нестандартная тема, логотип, название, фавикон, слоган

- Тема Bootstrap 5 установлена и назначена по умолчанию.
- Логотип — `scripts/assets/brand/logo.png`, фавикон — `scripts/assets/brand/favicon.png`,
  название сайта «Город24», слоган «Ноутбуки Lenovo с доставкой по Минску».
- Всё задано конфигом `system.theme` (`logo.use_default = FALSE`, `favicon.use_default = FALSE`),
  файлы лежат в `public://brand/`.

Скрыны: `task2a_тема_установлена_и_по_умолчанию.png`,
`task2b_настройки_темы_логотип_фавикон_слоган.png`.

### Задание 3 — минимум 5 модулей

Включено 7 contrib-модулей (страница Extend — `task3a_модули_включенные.png`):

### Задание 4 — алиасы и метаданные

- Pathauto: шаблоны `noutbuki/[node:title]` для типа «Ноутбук» и `[term:vocabulary]/[term:name]`
  для терминов; алиасы пересчитаны (`drush pathauto:aliases-generate`).
- Metatag: метатеги по умолчанию для всех материалов + поле «Метатеги» в форме материала
  (заголовок и описание заполняются для каждой карточки, выводятся в `<head>`).
- Real-time SEO: поле `field_yoast_seo` с ключевым словом, SEO-заголовком и описанием;
  библиотека анализа `rtseo.js` установлена в `web/libraries/rtseo.js`.

### Задание 5 — каталог ноутбуков (таксономия + свой тип материала)

- Словарь таксономии **«Lenovo»**, термины: «серия IdeaPad», «серия ThinkPad», «серия V»,
  «серия Yoga» (`task5d_словарь_lenovo_термины.png`).
- Тип материала **«Ноутбук»** (`noutbuk`), поля: `body`, `field_series` (термин словаря —
  обязательное), `field_model` (номер модели), `field_photo` (фотография).
  Состав полей — `task5c_поля_типа_материала_ноутбук.png`, форма создания —
  `task5e_форма_создания_ноутбука_обязательные_поля.png`.
- Каталог из **10 ноутбуков** с номером модели и фотографией; главная страница — каталог
  (`task5a_каталог_10_ноутбуков_главная.png`), карточка — `task5b_карточка_ноутбука_фото_серия_модель.png`.
- Image style `noutbuk_card` (400×250) для единообразных превью.

## Конфигурация кодом

Вся настройка сайта — в `scripts/lab8-config.php` (запускается через `drush php:script`):
таксономия, тип материала и поля, отображения формы и вывода, 10 карточек, image style,
веб-форма «Обратная связь» и её блок, паттерны Pathauto, метатеги, меню, главная страница.

Скрипт идемпотентен: повторный прогон обновляет существующие объекты, а не создаёт дубликаты
(материалы ищутся по заголовку, поля и отображения — по имени).

## Проверка

`setup-lab8.sh` в конце выполняет curl-проверки: главная отвечает, в каталоге есть карточки,
в коде страницы есть фото и `meta name="description"`, форма обратной связи отрисована.
