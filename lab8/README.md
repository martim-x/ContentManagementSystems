# ЛР8 — Drupal: знакомство с Drupal

Дисциплина «Системы управления контентом». Задание — `labs/Drupal/Drupal_1.pdf`
(в документе «Лабораторная работа №8»).

**Тематика сайта:** городской новостной портал «Город24» — лента городских новостей
с рубриками. Каталог ноутбуков Lenovo, который требует задание 5, оформлен как
отдельный раздел портала «Техника» (`/noutbuki`).

## Стенд

- Собственный `Dockerfile` (образ `drupal:11` + drush + настройки PHP), `docker-compose.yml`:
  проект `cms-drupal-lab8`, контейнеры `db8` / `web8` / `adminer8`.
- Drupal 11.4, тема **Bootstrap 5** (нестандартная), редакция `standard`.
- Порты: сайт **8104**, Adminer **8105**.

| Что | Адрес | Логин |
|---|---|---|
| Сайт | http://localhost:8104 | — |
| Админка | http://localhost:8104/user/login | `admin` / `Gorod24!Admin2026` |
| Adminer | http://localhost:8105 | сервер `db`, пользователь `drupal` |

## Запуск

```sh
cd lab8
docker compose up -d --wait
sh setup-lab8.sh      # идемпотентен: повторный запуск не создаёт дубликатов
```

### Задание 4 — алиасы и метаданные

- Pathauto: `novosti/[node:title]` для новостей и статей, `noutbuki/[node:title]` для
  каталога, `stranicy/[node:title]` для страниц, `rubrika/[term:name]` для рубрик
  (всего 5 шаблонов).
- Metatag: значения по умолчанию для всех материалов + поле «Метатеги» в форме новости
  (заголовок и описание заполнены у каждой новости и выводятся в `<head>`).
- Real-time SEO (`yoast_seo`): поле с ключевым словом, SEO-заголовком и описанием;
  библиотека анализа `rtseo.js` лежит в `scripts/libraries/` и копируется в `web/libraries`.
  Живой анализ работает после правки совместимости: кастомный модуль `gorod24_seo`
  (`scripts/modules/gorod24_seo/`, ставится `setup-lab8.sh`) выключает редактируемый
  сниппет, который падает на jQuery 4, и проставляет `id` служебным полям виджета.
  Проверено на форме новости: балл `Okay`, замечания по ключевому слову и длине заголовка.

## Конфигурация кодом

Вся настройка — в `scripts/lab8-config.php` (запускается через `drush php:script`):
тема и брендинг, стили изображений, словари «Рубрики новостей» и «Lenovo», типы материалов
«Новость» и «Ноутбук» с полями и отображениями, 13 новостей и 10 карточек, представление
`katalog` (страница `/noutbuki`), паттерны Pathauto, метатеги, веб-форма «Прислать новость»,
её блок в футере и главное меню.

Скрипт идемпотентен: материалы ищутся по заголовку, поля и отображения — по имени,
лишние материалы прошлых прогонов удаляются, алиасы перегенерируются Pathauto.

## Проверка

`setup-lab8.sh` в конце делает curl-проверки: главная отвечает и содержит ленту новостей
с иллюстрациями, метатег `description`, страница рубрики, каталог `/noutbuki`,
форма «Прислать новость».
