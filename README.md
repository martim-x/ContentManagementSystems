# Системы управления контентом

Учебный репозиторий по дисциплине «Системы управления контентом» (ИСиТ, 3 курс).

Преподаватель — доц. Шутько Н.П.

## Структура

- `lectures/` — лекции (чт 11.25–12.50, II неделя).
- `labs/` — лабораторные работы (сб 8.00–9.25, ауд. 413-1), сгруппированы по CMS:
  - `WordPress/` — ЛР 1–4, инструкции по установке и переносу сайта;
  - `Joomla/` — ЛР 1–4, справочный материал;
  - `Drupal/` — ЛР 1–5;
  - `Apex/` — ЛР 1–3;
  - `ЗФ/` — лабораторные заочной формы (ЛР 1–4).
- `labN/` — материалы и решения по конкретным лабораторным.

Дистрибутивы CMS (`*.zip`, `*.exe`) лежат рядом с лабами, но не версионируются — исключены `.gitignore`.
