# ЛР3: Работа с WP Elementor. Создание шаблона

Стенд новостного портала «Город24» (тема из вёрстки ЛР1) для лабораторной №3 курса
«Системы управления контентом». Каталог самодостаточный: compose, скрипты, тема,
скриншоты — всё внутри. Зависимостей от `lab2/` нет.

## Как запустить

```bash
docker compose up -d
sh setup-lab3.sh
```

Первый запуск разворачивает всё с нуля: WordPress, плагины, тему, контент, лендинг,
шаблон и страницу блоков. Повторный запуск ничего не ломает — все шаги идемпотентны.

## Доступ

| Что | Адрес | Логин |
|---|---|---|
| Сайт | http://localhost:8090 | — |
| Админка | http://localhost:8090/wp-admin | `admin` / `admin123` |
| phpMyAdmin | http://localhost:8092 | `wp` / `wppass` |

Порты 8090/8092 — чтобы стенды лабораторных не конфликтовали между собой
(`lab2/` занимает 8080/8082).

## Что внутри

| Файл | Назначение |
|---|---|
| `docker-compose.yml` | стенд: WordPress, MariaDB, WP-CLI, phpMyAdmin |

| `scripts/setup-content.php` | базовый контент портала: меню, записи, рубрики, настройки |

Контейнеры: `lab3-db`, `lab3-web`, `lab3-phpmyadmin`, `lab3-wpcli`.
Тома: `cms-lab3-db-data`, `cms-lab3-wp-data` — `docker compose down` их не трогает,
полный сброс только через `docker compose down -v`.

### Задание 1 — лендинг (8 секций)

Страница `/` «Лендинг Город24», назначена главной страницей сайта.

1. hero: заголовок, текст, кнопка «Читать новости»;
2. заголовок «Разделы портала»;
3. три колонки icon-box: Политика / Экономика / Спорт;
4. две колонки: карточка главной новости «Немига-2» и текст с кнопкой;
5. культура и события;
6. три колонки счётчиков: 120 новостей в неделю, 48 проверенных источников, 7 лет с редакцией;
7. цитата редакции (бесплатный виджет toggle);
8. две колонки: текст «Предложить новость» и форма Contact Form 7.

Тема — `gorod24`, та же, что выбрана на первом занятии.

### Задание 2 — шаблон

Шаблон «Шаблон страницы Город24» сохранён в библиотеке Elementor (Шаблоны → Мои
шаблоны, тип Page). Из него собрана страница `/reklama/`: в её метаданных
`_elementor_template_id` ссылается на шаблон, а `_elementor_data` идентичен шаблону.

### Задание 3 — встроенный ИИ (вручную)

Требует входа в аккаунт Elementor AI, поэтому автоматизировать нельзя. На защите:
открыть редактор Elementor → кликнуть иконку «✨» у поля текста или цвета → показать
окно с вариантами подсказок.

### Задание 4 — блоки из каждой группы

Страница `/bloki/`: Текст (абзац, заголовок, список, цитата), Медиа (обложка, галерея,
файл), Дизайн (кнопки, разделитель, колонки, таблица), Виджеты (поиск, свежие записи,
рубрики), Тема (название и слоган сайта), Встраивания (YouTube), Шаблоны
(синхронизированный блок «Блок портала Город24»).

### Задание 5 — плагины блоков

Kadence Blocks (59 блоков) и Stackable — Gutenberg Blocks (47 блоков), оба активны.

## Что было исправлено при проверке

Лендинг был сделан, но фактически не работал — восемь дефектов:

- **колонки схлопывались:** хелпер принимал ассоциативный массив с ключом `33 => …`
  трижды; PHP оставлял один элемент, и три колонки превращались в одну;
- **счётчики показывали 0:** использовалось поле `number`, которого у виджета нет —
  Elementor ждёт `starting_number` и `ending_number`;
- **цитата не отображалась:** виджет `blockquote` в Elementor 4.x входит в PRO и без
  лицензии подменяется пустой заглушкой; заменён на бесплатный `toggle`;
- **toggle печатал «Toggle #1»:** поля `tab_title` и `tab_content` лежат внутри
  повторителя `tabs`, а не на верхнем уровне виджета;
- **image-box показывал Lorem ipsum:** поля называются `title_text` и `description_text`;
- **версия Elementor** была зашита как `3.0.0` вместо установленной 4.3.2;
- **скрипт не был идемпотентным:** каждый прогон создавал новые страницы;
- **задание 4 покрывало 5 групп из 7:** добавлены «Тема» и «Шаблоны».
