# ЛР5 — Joomla: ленты новостей и ссылок, свой модуль

Дисциплина «Системы управления контентом». Задание — `labs/Joomla/Joomla_4.pdf`
(в нумерации практикума Joomla это ЛР4):

1. Для сайта из прошлой лабораторной стандартными средствами создайте ленту
   новостей и настройте её.
2. Добавьте в любую статью ссылку на другой материал.
3. Модуль компактной формы контакта: сворачивается до кнопки, разворачивается
   обратно; три поля — имя, email, текст обращения; цвет и вид — на свой вкус.
4. Защита модуля: капча «сложение двух цифр».

Сайт — «Город24» из ЛР1 (`lab1/site`), CMS — Joomla 5.4.9 в собственном образе.

## Стенд (Docker)

| Что | Значение |
|---|---|
| Собственный образ | `lab5/Dockerfile` (база `joomla:5` + лимиты PHP + скрипты лабы) |
| docker-compose | `lab5/docker-compose.yml`, проект `cms-joomla-lab5` |
| Контейнеры | `web5` (Joomla, порт 8098), `db5` (MariaDB 11), `phpmyadmin5` (порт 8100) — постфиксы, чтобы лаба 5 работала одновременно с лабой 6 |
| Volumes | `cms-joomla-lab5_joomla_data` (файлы CMS), `cms-joomla-lab5_db_data` (БД) — named, переживают `down` |
| Админка | http://localhost:8098/administrator — `admin` / `admin` |
| phpMyAdmin | http://localhost:8100 — `joomla` / `joomla` |

## Команды (копипастные)

Из каталога `lab5`:

```sh
docker compose up -d --wait
sh setup-lab5.sh
```

`setup-lab5.sh` идемпотентен: ставит Joomla (если чистый том), копирует скрипты
и файлы модуля в том, наполняет сайт, регистрирует модуль, пересобирает деревья
меню/категорий и в конце прогоняет curl-проверки всех страниц задания.

Полный сброс с удалением контента:

```sh
docker compose down -v
sh setup-lab5.sh
```

Остановка без потери данных: `docker compose down`.

## Карта задания: где что смотреть

| Задание | Где проверять |
|---|---|
| 1. Лента новостей | страница «RSS-лента»: http://localhost:8098/rss-lenta (модуль показывает RSS); сам фид: http://localhost:8098/index.php?view=category&id=8&format=feed&type=rss; запись ленты в админке: «Компоненты → Ленты новостей» («Новости Город24») |
| 2. Ссылка на материал | статья «Новый трамвай вышел на линию 5»: http://localhost:8098/novosti/novytramvay-v-minske — строка «Читайте также: Школу №110…»; поле задано в админке: «Материалы → Новый трамвай… → вкладка Ссылки» |
| 3-4. Форма контакта с капчей | модуль «Написать в редакцию» на http://localhost:8098/ — сворачивается по кнопке «Написать нам», поля: имя, email, текст обращения, капча «сложение двух цифр»; обращения пишутся в `administrator/logs/g24contact.log` (SMTP на стенде не настроен) |

## Файлы лабы

| Файл | Назначение |
|---|---|
| `Dockerfile` | собственный образ: `joomla:5` + настройки PHP (upload 32M, память 256M) + скрипты лабы внутри дистрибутива |
| `docker-compose.yml` | три сервиса (`web`, `db`, `phpmyadmin`), named volumes `joomla_data`, `db_data` |
| `setup-lab5.sh` | полное развёртывание и проверка стенда одной командой |
| `make-ru-language.sh` | сборка русского языкового пакета ru-RU (официальный downloads.joomla.org в момент сборки отдавал 500) |
| `scripts/lab5-install.php` | установка Joomla без мастера: configuration.php, пользователь admin, главное меню |
| `scripts/lab5-content.php` | категория «Новости», 6 статей, лента com_newsfeeds, модуль mod_feed, пункт меню ленты, ссылка «Читайте также» (urls.urla) |
| `scripts/lab5-module.php` | регистрация модуля `mod_gorod24contact` и привязка к главной |
| `scripts/lab5-finish.php` | язык ru-RU, главная (featured), CSS модуля |
| `scripts/lab5-menu-tree.php` | пересборка Nested-деревьев jos_menu и jos_categories штатным Table::rebuild() |
| `module/mod_gorod24contact/` | исходники модуля формы контакта (сворачивание, капча, отправка в лог) |
| `report/` | скриншоты контрольных точек для защиты |
